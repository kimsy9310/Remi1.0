# 관능 앵커를 정하는 전략 — 리서치

2026-09-02. `docs/척도정의_전략.md` 6.2 절("앵커 문장은 이렇게 고친다")의 근거
문서다. 그쪽이 결론이라면 이 문서는 **왜 그 형태인가**와 **무엇으로 검증하는가**다.

앵커를 정하는 일은 문장 70쌍을 쓰는 일이 아니다. 세 가지를 정하는 일이다.

| 층 | 무엇을 정하나 | 지금 우리 상태 |
|---|---|---|
| **L0 척도 끝** | 0 과 ±3 이 무슨 사건인가 | 정했다 — 전략 문서 3 절 |
| **L1 중간 눈금** | ±1, ±2 를 무슨 말로 부르나 | **비어 있다.** 카드에 −3/0/+3 만 있다 |
| **L2 물리 앵커** | 실물 시료로 눈금을 못 박을 것인가 | 없다. 벤치마크 하나뿐 |

---

## 1. 문헌이 확인해 준 것

### 1.1 말은 저절로 등간이 아니다 — 배치는 재는 것이다

Rohrmann(2007)은 척도 라벨 100개를 0~10 위에 놓게 해서 **평균 위치와 분산**을
쟀다. 라벨을 고르는 기준이 둘이라는 것이 요점이다.

- **평균이 목표 위치에 있을 것** (5점 척도면 0/2.5/5/7.5/10 또는 1/3/5/7/9)
- **분산이 작을 것** — 사람마다 뜻이 갈리지 않을 것("언어적 변별력")

그리고 **분산은 중간 라벨에서 가장 크다.** "not at all", "always" 같은 끝말은
거의 모호하지 않은데, "quite", "rather", "somewhat" 은 사람마다 크게 어긋난다.
저자가 예로 든 것: "rather"와 "quite"는 5점 척도의 4번 자리(≈6.5)에 쓰여 왔지만
실측 위치가 그렇지 않았다.

> **우리에게 뜻하는 것.** 지금 슬라이더의 "조금 덜하게 / 많이 덜하게" 가 정확히
> 그 위험 구간의 말이다. **가장 흔들리는 자리(±1, ±2)에 가장 흔들리는 종류의
> 말(정도 부사)을 놓았다.**

### 1.2 그래서 부사 대신 **절차**를 쓴다

전략 문서가 택한 "나란히 비교하면 안다 / 따로 맛봐도 안다" 는 정도 부사가
아니라 **판별 절차**다. 절차는 사람마다 뜻이 갈리지 않는다 — 두 잔을 나란히
놓았는지 아닌지는 관찰 가능한 사실이다. 1.1 의 "분산이 작을 것" 을 정도 표현이
아닌 방식으로 만족시키는 것이 이 선택의 핵심이다.

이 발상 자체는 새롭지 않다. 감각 차이 검정의 표준 척도(difference-from-control)가
`없음 / 아주 약간 / 약간 / 보통 / 큼 / 매우 큼` 으로 **차이의 크기**를 묻는 것과,
LMS(Green 1993)가 아래 끝을 "barely detectable"(겨우 감지됨)로 잡는 것이 같은
계열이다. 우리는 거기서 한 걸음 더 가서 "무슨 조건에서 감지되는가" 로 적었다.

### 1.3 라벨 배치를 재는 값싼 방법이 있다

Rohrmann 은 범주 척도(0~10에 단어 놓기)와 크기 추정(magnitude estimation)을 둘
다 돌렸는데, **두 결과의 상관이 0.98~0.99** 였다. 크기 추정은 참가자들이
"낯설고 어렵고 부자연스럽다" 고 답한 과제다.

> **우리에게 뜻하는 것.** 비싼 방법을 쓸 이유가 없다. **"이 문장이 뜻하는 차이를
> 0~10 사이에 놓아 보세요"** 로 충분하다. 6 절의 검증 절차 (가) 가 이것이다.

### 1.4 끝 앵커의 문구는 **사용 범위**를 바꾸지만 **변별력**은 안 바꾼다

Cardello·Lawless·Schutz 는 LAM 척도의 끝 앵커를 "이 음료 중에서 가장 좋음" 과
"어떤 경험이든 통틀어 가장 좋음" 으로 바꿔 비교했다. 범위를 넓게 잡은 쪽에서
**응답이 눌려 좁은 구간만 쓰였다.** 그런데 **제품을 가려내는 능력은 세 판본이
같았다.**

> **우리에게 뜻하는 것 두 가지.**
> ⑴ 문구를 완벽하게 고르려고 시간을 쓸 필요가 없다. 웬만하면 변별은 된다.
> ⑵ 대신 **한 번 정하면 바꾸지 말 것.** 문구를 바꾸면 눈금의 뜻이 이동해서
> 예전 데이터와 새 데이터를 같은 척도로 볼 수 없게 된다. 앵커는 데이터의
> 일부다.

### 1.5 척도 끝은 원래 잘 안 쓰인다 — 그리고 한국어권은 더 그렇다

- 응답자가 극단 범주를 피해서 9점 척도가 사실상 7점으로 줄어든다는 보고가
  반복돼 있다. Rohrmann 도 같은 경고를 한다 — 극단 라벨을 쓰면 5점이 사실상
  3점이 되므로, 끝 라벨을 아예 뺄지 사전 검사로 정하라고 권한다.
- Chen·Lee·Stevenson(1995)은 7점 리커트 57개에서 **동아시아 학생이 북미
  학생보다 중앙값을 많이 쓰고 극단값을 적게 썼다.**
- 우리 데이터가 그대로다: 101개 점수 중 **87%가 [−1, +1]**, +3 은 0회.

> **우리에게 뜻하는 것.** ±3 자리에 의사결정을 걸면 안 된다. 이미 내린 결정
> (목표 입력 ±2 / 실측 기록 ±3)이 이 근거 위에 선다. **±3 은 "여기서부터는
> 다른 제품" 이라는 경계 표시로만 쓰고, 세밀한 조절은 ±1~±2 에서 일어난다.**

### 1.6 번역은 앵커가 아니다

여러 언어의 라벨이 서로 등가인지는 **대개 알려져 있지 않다**는 것이 이 분야의
표준적 경고다(Rohrmann 2007; 소음 반응 척도만 예외적으로 국제 표준화가 됐다).

> **우리에게 뜻하는 것.** 카드의 영문 `anchors` 와 한글 `ko.anchors` 는 **같은
> 도구의 두 표기가 아니라 서로 다른 도구다.** 사용자가 읽는 것은 한글이므로
> **한글이 정본**이고, 영문은 온톨로지의 원문 기록으로 남긴다. 지금 코드가
> 한글을 우선하는 것(`interview._question`)은 맞는 처리다. 앞으로 영문 앵커를
> 기계 번역해 한글을 채우는 일은 하지 않는다.

### 1.7 절대 강도 앵커는 다른 종목이다

Spectrum 방식은 여러 축에 걸쳐 **강도가 같은 실물 기준점**을 배치해서 축 사이
비교까지 가능하게 만든다(단맛 기준점과 짠맛 기준점이 같은 강도가 되도록 맞추는
연구가 따로 있을 정도다). 이것이 카드 4장에 들어 있는
`anchors: [{intensity: 3, reference: ...}]` 의 계보다.

> **우리에게 뜻하는 것.** 이건 훈련된 패널과 기준 시료 세트를 전제한 도구다.
> 우리 척도(벤치마크 대비 차이)와 **좌표계가 다르다.** 없애지는 말고 이름을
> 갈라 둔다 — 전략 문서 6.3.

## 2. 앵커를 정하는 다섯 가지 방식 — 무엇이 우리 것인가

| 방식 | 무엇으로 눈금을 못 박나 | 필요한 것 | 우리에게 |
|---|---|---|---|
| ㉠ 정도 부사만 | "조금 / 많이" | 없음 | **지금 상태.** 중간 눈금 분산이 가장 큰 조합(1.1) |
| ㉡ 판별 절차 | "나란히 비교하면 / 따로 맛봐도" | 없음 | **채택.** 훈련·시료·비용 0 |
| ㉢ 물리 기준 시료 (Spectrum) | 실물 시료 세트 | 훈련 패널 + 시료 유지 | 못 한다. 축 70개에 세트를 유지할 수 없다 |
| ㉣ 경험적 배치 (LMS) | 라벨의 실측 위치(준로그) | 라벨 조사 1회 | **부분 채택** — 6절 (가)로 위치만 점검 |
| ㉤ 기준 시료 하나 (DFC) | 벤치마크 그 자체 | 벤치마크 1종 | **이미 채택.** 우리 척도의 뿌리 |

㉡+㉤ 이 우리 조합이고, ㉣ 는 그 조합이 실제로 등간인지 확인하는 값싼 점검이다.

## 3. 권고 — 3층 앵커

### L0. 척도 전역 정의 (한 곳에 한 번)

전략 문서 6.1 의 설명 카드. **축마다 반복하지 않는다.** 70장에 같은 설명을
넣으면 읽히지 않고, 고칠 때 70곳을 고쳐야 한다.

### L1. 축별 문장 = 공통 틀 + 형용사 한 쌍

축이 실제로 제공하는 정보는 **비교 형용사 한 쌍**뿐이다. 나머지는 전 축 공통이다.

    틀(코드/도구가 갖는다)          축이 갖는 것(온톨로지)
    ─────────────────────────────   ────────────────────────
    ±1  "나란히 비교하면 {A}"        A = "더 달다"
    ±2  "따로 맛봐도 {A}"            B = "덜 달다"
    ±3  "다른 제품이라고 할 만큼 {A}"
     0  "기준과 구분되지 않는다"

이 분리가 중요한 이유는 1.4 다. **앵커 문구는 한 번 정하면 못 바꾼다.** 틀이
한 곳에 있으면 "못 바꾼다" 를 지킬 수 있다. 70장에 흩어져 있으면 언젠가
어긋난다 — 지금 `ko.anchors` 70장이 정확히 그 위험 상태다.

### L2. 물리 앵커는 딱 두 개만 둔다

축마다 기준 시료를 만드는 일(㉢)은 하지 않는다. 대신:

1. **벤치마크** — 사용자가 ① 에서 지정한 제품. 이것이 0 이다.
2. **블라인드 대조** — 벤치마크를 코드만 붙여 시료 세트에 한 번 더 넣는다.

2번이 DFC 의 표준 관행이다. 기준을 밝혀 준 채로 주고, 코드 붙인 시료들 속에
같은 것을 하나 더 섞어 평가시킨 뒤, **블라인드 대조가 받은 점수를 기준선으로
빼 준다.** 이것이 사 주는 것이 셋이다:

- **0 점이 진짜 0 인지 확인** — 블라인드 대조가 −0.7 을 받으면 그 사람의 0 은
  0 이 아니다
- **반복 측정 한 건이 공짜로 생긴다** → σ 의 첫 추정치. 전략 문서 7.3 이
  "반복이 한 건도 없다" 고 지적한 그 구멍을 시료 하나로 메운다
- 훈련 없는 평가자에게 **자기 눈금을 스스로 교정할 기회**

**비용은 시료 한 개다.** 지금 할 수 있는 앵커 보강 중 가장 싸고 효과가 크다.

## 4. 한국어 문구 규칙

1. **중간 눈금(±1, ±2)에 정도 부사를 쓰지 않는다.** 절차로 쓴다(1.1, 1.2).
2. **짧고 흔한 말.** Rohrmann 의 관찰 — 여러 단어로 이어 붙인 표현과 잘 안 쓰는
   부사형은 친숙도가 떨어진다.
3. **끝값은 경계 표시로 쓴다.** ±3 은 "다른 제품" — 자주 쓰이지 않을 것을
   전제로 설계한다(1.5).
4. **번역하지 않는다.** 한글 문장을 직접 짓는다(1.6).
5. **한 번 정하면 고정.** 바꿔야 하면 버전을 올리고 이전 데이터에 표시를
   남긴다(1.4).
6. **부호의 뜻을 문장이 스스로 말하게 한다.** "덜 달다 / 더 달다" 처럼 방향
   형용사를 넣는다. 슬라이더 위치만으로 방향을 기억하게 하지 않는다.

권고안(전략 문서 6.2와 같다):

| | 문장 | 슬라이더 눈금 |
|---|---|---|
| −3 | 다른 제품이라고 할 만큼 덜 달다 | (목표에는 없음) |
| −2 | 따로 맛봐도 덜 달다 | 따로 맛봐도 덜하게 |
| −1 | 나란히 비교하면 덜 달다 | 비교하면 덜하게 |
| 0 | 기준과 구분되지 않는다 | 기준과 같게 |
| +1 | 나란히 비교하면 더 달다 | 비교하면 더 |
| +2 | 따로 맛봐도 더 달다 | 따로 맛봐도 더 |
| +3 | 다른 제품이라고 할 만큼 더 달다 | (목표에는 없음) |

향 축은 "덜/더" 대신 그 축의 동사를 쓴다 — 여운은 "빨리 가신다 / 오래 간다",
꺼끌거림은 "덜 꺼끌거린다 / 더 꺼끌거린다".

## 5. 하지 않기로 한 것

| | 왜 |
|---|---|
| 축 70개에 실물 기준 시료 세트(Spectrum) | 훈련 패널과 시료 유지가 전제. 우리 조건이 아니다 |
| LMS 식 준로그 배치 | 우리 척도는 절대 강도가 아니라 차이다. 준로그로 놓을 근거가 없고, 엔진의 등간 가정과 충돌한다 |
| 영문 앵커를 번역해 한글 채우기 | 1.6 |
| 완벽한 문구를 찾기 위한 반복 | 1.4 — 변별력은 문구에 크게 안 달렸다. 고정이 더 중요하다 |
| ±0.5 라벨에 이름 붙이기 | 0.5 는 "그 둘 사이" 라는 뜻이면 충분하다. 이름을 붙이면 라벨 13개가 된다 |

## 6. 앵커를 검증하는 값싼 절차 세 가지

앵커는 정하고 끝나는 것이 아니라 **쓰이는 모양을 봐야** 옳았는지 안다.

### (가) 문장 배치 조사 — 1회, 30분, 사람 8~12명

1.3 이 근거다. 크기 추정 같은 어려운 과제가 필요 없다.

> "아래 문장이 뜻하는 **차이의 크기**를 0(차이 없음) ~ 10(완전히 다른 제품)
> 사이의 숫자로 적어 주세요."
> — 나란히 비교하면 더 달다 / 따로 맛봐도 더 달다 / 다른 제품이라고 할 만큼 더 달다

보는 것 둘: **평균이 순서대로 벌어지는가**(등간에 가까운가), **표준편차가
큰 문장이 있는가**(뜻이 갈리는 말). sd 가 큰 문장만 손본다.
합격선은 미리 정한다 — 예: 인접 문장의 평균 간격 ≥ 2.0, 각 문장 sd ≤ 2.0.

### (나) 블라인드 대조 — 실험할 때마다

3 절 L2. 블라인드 대조가 받은 점수가 |0.5| 를 넘으면 그 회차의 0 점은 못 믿는다.
회차가 쌓이면 그 값들의 흩어짐이 곧 σ 다.

### (다) 사용 분포 감시 — 데이터가 쌓이는 대로 자동

지금 데이터로 이미 계산되는 것들이다(전략 문서 2 절). 앱이 주기적으로 보면 된다:

| 지표 | 지금 값 | 뜻하는 것 |
|---|---|---|
| ±3 사용률 | 1/101 (1%) | 끝값이 사실상 안 쓰인다 → 경계 표시로만 (1.5) |
| [−1,+1] 비율 | 87% | 실사용 구간이 좁다 → ±1 부근의 문장이 가장 중요하다 |
| 0.5 사용률 | 11% | 사용자가 더 잘게 답하고 싶어 한다 → 0.5 허용은 요구에 맞다 |
| 축별 사용 폭 | 0.68~0.97 | σ_medium=1.0 과 같은 크기 → (나)가 급하다 |

## 7. 온톨로지에 어떻게 담을 것인가

지금(문장 3개를 카드가 통째로 갖는다 — 틀이 70곳에 복제돼 있다):

    ko:
      anchors:
        '-3': '기준보다 뚜렷하게 덜 달다'
        '0':  '기준과 구분되지 않는다'
        '+3': '기준보다 뚜렷하게 더 달다'

권고(카드는 형용사 쌍만 갖고, 문장은 도구가 만든다):

    ko:
      contrast: ['덜 달다', '더 달다']     # ← 축이 갖는 유일한 정보
      anchors:                              # ← 도구가 채워 넣은 결과. 사람이 검수
        '-3': '다른 제품이라고 할 만큼 덜 달다'
        ...
        '+3': '다른 제품이라고 할 만큼 더 달다'

`anchors` 를 생성해 두고 파일에 남기는 이유: 로더와 앱이 지금 형태 그대로 읽고,
사람이 어색한 문장을 손으로 고칠 수 있다. `contrast` 는 그 문장을 다시 만들 때의
씨앗이다. 생성기는 `tools/add_korean_cards.py` 를 확장한다.

절대 강도 기준점 4장은 `intensity_references:` 로 분리한다(1.7, 전략 6.3).

## 8. 실행 순서 (전략 문서 9 절과 합쳐 읽을 것)

1. **(나) 블라인드 대조를 데이터 템플릿에 넣는다.** 시료 하나 값이고 σ 와
   0점 검증을 동시에 산다. 다른 어떤 항목보다 먼저다.
2. `ko.contrast` 를 70장에 채우고 `ko.anchors` 7단계를 생성한다(7 절).
3. 슬라이더 눈금 문구 교체(4 절 표).
4. **(가) 문장 배치 조사**는 2~3 이 화면에 붙은 뒤에 한다. 실물을 보고 답하는
   편이 낫고, 결과가 나쁘면 고칠 곳이 `contrast` 와 틀 한 곳뿐이다.
5. (다) 사용 분포 감시는 데이터가 두 번째 프로젝트로 넘어갈 때 붙인다.
