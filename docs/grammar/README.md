# Remi 문법 — 모든 세션이 같은 말을 쓰기 위한 규칙

2026-09-12. 사용자 결정: **설계는 S1 이 하고 구현은 S5 / Remi 1.1 이 한다. S1 은 기본
문법을 정한다.** 이 폴더가 그 문법이다. 다른 세션은 여기 적힌 이름·형식만 쓰고,
없는 것은 여기에 먼저 더한 뒤 쓴다.

왜 필요한가 — 파일이 많아지면서 같은 것을 다른 말로 부르는 곳이 늘었다. 재 보니
(01장 현황) 이름공간 15개 중 3개가 v1 잔재이고, 스코프 표기가 두 가지이며, 제품 하나를
가리키는 이름이 일곱 가지다. 세션을 기능별로 가른 뒤에는 이것이 곧바로 사고가 된다.

나머지가 그 말로 쓰인다.

## 장마다 같은 다섯 절

    현황    지금 어디에 무엇이 어떻게 적혀 있나 — 재 본 숫자로
    규칙    번호 붙인 문장. 기계로 검사할 수 있는 것만 규칙이다
    예 · 반례
    검사    어느 selfcheck 줄이 이 규칙을 지키는지 (없으면 "없음 — 만들 것")
    판단    규칙이 못 되고 사람이 정해야 하는 것. 여기 남은 것은 사용자에게 묻는다

## 소유

`docs/grammar/` 는 S1 이 쓴다. 다른 세션은 읽고, 어긋나는 것을 찾으면 S1 에 보고한다.
규칙을 코드·YAML 에 반영하는 것(필드 이름 바꾸기, 별칭 정리)은 **Remi 1.1 이관 항목**
으로 [00_change.md](00_change.md) 끝의 표에 쌓는다 — 지금 파일을 대량으로 바꾸지 않는다.
