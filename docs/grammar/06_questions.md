## 이 장이 정하는 것과 아닌 것

A3 `DISAMBIGUATE` 의 문법. 질문은 사람이 쓰는 것이 아니라 **Output 4 의 빈 자리**가
만든다 — profile 이 후보 여럿이면 제형 질문, identity 가 2개 미만이면 정체성 질문,
unresolved 가 있으면 뜻 질문. 무엇이 비면 무엇을 묻나, 한 번에 몇 개, 언제 그만 묻나,
질문 문장의 꼴(보기는 항상 ID 로 제한) 을 정한다.

| | 누가 |
|---|---|
| 질문의 종류 · 우선순위 · 종료 조건 · 문장 꼴 | S1 — 이 장 |
| locale 별 실제 문장 · 매핑표 | S4 |
| 화면 | S5 |
