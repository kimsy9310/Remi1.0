# 03 술어 — 관계는 형식이 문법이고 값은 지식이다. 스코프는 사다리 한 줄이다

뼈대 2026-09-12 (S1). 01·02장 확정 뒤 쓴다.

## 이 장이 정하는 것과 아닌 것

관계(술어)는 네 가지다. 각각 **형식**(어떤 필드가 있고 어떤 값을 받나)과 **값**(이 관계가
실제로 얼마나 센가)으로 나뉜다. 문법은 형식만 정한다.

| 관계 | 무엇 → 무엇 | 파일 | 형식(문법) | 값(지식) | 값을 숫자로(모형) |
|---|---|---|---|---|---|
| INGREDIENT 엣지 | `ING`/`FT` → `P` | `layerC2_*` | S1 | **S2** | S3 |
| R-1 | `P` → `L` | `layerR_seed` | S1 | S1 | S3 |
| R-2 | `L` ↔ `L` | `layerR_seed` | S1 | S1 | S3 |
| R-3 | 목표 이동 (DELTA) | 로더 상수 | S1 | S1 | S3 |

즉 S1 은 (1) 네 관계의 필드·값 집합, (2) 스코프 사다리(어느 단에 적힌 관계가 어디까지
물려지나 — `any` → `SC` → `SC|APP` → `SC|APP|ST`), (3) 같은 관계가 두 단에 있을 때
누가 이기나(잎이 이긴다), (4) 반대 부호가 두 스코프에 공존할 수 있는 조건 — 을 정한다.
개별 엣지의 세기·용량은 S2 의 것이고, `strong` 이 Γ₀ 에서 몇인지는 S3 의 것이다.
