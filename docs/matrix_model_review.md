# Matrix model review — 손글씨 설계안(v(ING)·Γ·M·역산)의 검토

2026-09-19. 사용자가 적은 행렬 설계안(2026-09-19 수정본, 6항 + 고안점 4)을 remi 의
현재 모형(`docs/모형_수학_해설.md`, `engine/formulator/mixture.py`, `v2adapter.py`,
`app/warmloop.py`)과 행렬 연산 수준에서 대조했다. 판정 · 이유 · 대체안 · 수치 실험 순.
S3 MODEL 의 문서다. 말은 법전(`docs/grammar/RULES.en.md`)을 따른다.

## 0. 한눈에

| 항 | 설계안 | 판정 | 한 줄 |
|---|---|---|---|
| 1 | `v(ING) = A·B + C`, `B ∈ ℝ^{L×L}` 이 `[SC, APP, ST]` 를 반영 | **수정** | 꼴은 맞고 **가운데 공간이 틀렸다** — `L×L` 이 아니라 `P×L`(물성→감각). `L×L` 이면 A 와 B 가 식별되지 않고 칸이 30만 개다 (§2) |
| 2 | `Γ = stack v(ING) ∈ ℝ^{#ING×L}` | **그대로** | remi 의 `Γ₀`. 단, 필러 행을 빼 `(#ING−1)×m` 이고 열은 제형 카드의 축 m 개만 (§3) |
| 3-2 | `S = x·Γ`, `Σx = 100` | **수정** | 합 제약 때문에 절편이 식별 안 됨 → 필러 기준 좌표 `z`, 표준화 `(z−z̄)/s`, 그리고 `S` 는 **벤치마크 대비 Δ** (§4) |
| 3-1 | `S' = S + S·M`, `M ∈ ℝ^{L×L}` | **위치 변경** | 예측식에 넣으면 `Γ(I+M)` 과 동치라 M 이 데이터에서 식별 불가 + 이중 계산. **목표 이동(R-3)·Σ₀·설명**에 쓴다 (§5, 고안점 3) |
| 4 | `S_t = S_0·Γ + S_k`, 역산으로 `S_0` | **차원 오류 + 대체** | `S_0(1×L)·Γ(#ING×L)` 은 곱이 안 된다. 뜻은 `x_0·Γ`. `S_k` 는 상수가 아니라 **벤치마크 관능**이고, 벤치마크 대비 척도에서 0 (§6). 역산은 의사역행렬이 아니라 **제약 QP** — 실제 사례에서 의사역행렬은 잔탄검 −0.68% 를 낸다 (§7, 고안점 2) |
| 5 | `ΔS = Δx·Γ` 로 `Δx` 역산, `S'_1 = (S_0+Δx)M + (S_0+Δx)` | **불가 → 대체** | `S_0(1×L) + Δx(1×#ING)` 은 더할 수 없다. 더 근본적으로 **틀린 Γ 로 반복 역산하면 발산**한다(시뮬레이션 §8: 부호 20% 틀리면 85% 가 발산). 잔차는 배합이 아니라 **Γ 를 갱신**하는 데 쓴다 = 웜루프 (§8) |
| 6 | GP·확신도를 어디에 | **답** | 확신도는 이미 `Λ`(사전 정밀도)·`Σ₀`·예측분산에 들어가 있다. GP 는 지금 n(5~20) 으로는 서로게이트로 못 쓰고, DoE 에 획득함수로 쓰면 특허 B-28 과 겹친다. D-최적 설계로 간다 (§9, 고안점 4) |

**비효율의 정체는 계산이 아니다.** q ≤ 30, m ≤ 16 이라 어떤 식이든 마이크로초다. 문제는
셋 — **채울 수 없는 칸 수**(항 1), **식별 불능**(항 1·3), **제약 위반과 발산**(항 4·5).

## 1. 기호 — 설계안의 표기를 이 문서의 표기로

| 설계안 | 여기 | 크기 | 뜻 |
|---|---|---|---|
| `#ING` | p | 10~30 | 팔레트의 재료 수 (필러 포함) |
| — | q = p − 1 | | 필러를 뺀 자유변수 수 |
| `#L` | L = 216 | | LEXICON 전체 |
| — | m | 5~16 | **이 제형 카드의 축 수.** Γ 의 열은 L 이 아니라 m 개다 |
| — | P = 39 | | PARAMETER (물성) |
| `x` | x ∈ ℝ^p, z ∈ ℝ^q | | 배합 (합 100), 필러 뺀 배합 |
| `v(ING)` | γ_j ∈ ℝ^m | | 재료 j 의 벡터 (법전 §0: 컴포넌트를 모은 것) |
| `Γ` | Γ₀ ∈ ℝ^{q×m} | | 사전 행렬 (ING × L) |

| `S_k` | ȳ | | 절편 |

(`Y = Zc @ G`). 해설 문서의 `y = Γᵀz` 는 열벡터 표기일 뿐 같은 식이다.

## 2. 항 1 — `v(ING) = A·B + C` 와 고안점 1

### 2.1 차원은 맞는다. 공간이 틀렸다

`A(1×L)·B(L×L) + C(1×L)` 은 곱셈이 성립한다. 그런데 A 가 **이미 감각 공간(L)** 에 있으면
B 는 "감각을 감각으로 다시 섞는" 행렬이다. 제형이 재료에 하는 일은 그게 아니다 —
지방 5% 는 소스에서는 **점도**를 올리고 음료에서는 **크리밍**을 일으킨다. 갈라지는 자리는
**물성(P)** 이지 감각이 아니다. 그래서 remi 는 같은 꼴을 이렇게 쓴다:

    v(ING) = A_P · B_profile + C
             ─┬─   ────┬────   ─┬─
              │        │        └ 직접 감각 컴포넌트 (1×m)      INGREDIENT 의 L.* 엣지
              │        └ 물성 → 감각 (P×m), 제형 스코프          PARAMETER 의 P.axes (옛 PO, R-1)
              └ 재료 → 물성 (1×P), 제형에 거의 무관              INGREDIENT 의 P.* 엣지

`[SC, APP, ST]` 는 **B 의 첨자**다 — 컴포넌트마다 `scope` 가 달려 있고(C1), 제형 튜플로
매칭해서(B5) 그 제형의 B 를 조립한다. 코드로는 `loader_reference.effects_of` 가 이 곱을
수행하고, 우선순위(재료 직접 > 태그, 직접 L.* > 합성, 합성끼리는 |크기| 최대)를 정한다.

### 2.2 `L×L` 이 왜 안 되나 — 셋

**(a) 식별.** `v = A(B + I)` 꼴이 되어 (A, B) 와 (A', B') = (A(B+I), 0) 이 같은 v 를 준다.
A 와 B 를 서로 다른 출처로 채워야만 갈린다. `P` 를 끼우면 A 는 재료의 물리(문헌·실측
가능), B 는 정신물리(psychophysics, 제형마다 다름)라 출처가 다르다. `L×L` 이면 둘 다
"감각" 이라 갈리지 않는다.

**(b) 칸 수.** 채워야 할 칸을 세면:

| 설계 | 칸 | 채워진 것 |
|---|---|---|
| `B ∈ ℝ^{L×L}` × 제형 7 | 216² × 7 = **326,592** | 0 |
| `B ∈ ℝ^{P×L}` (스코프 첨자) | 39 × 216 = 8,424 | `P.axes` **70** 컴포넌트, 그것으로 충분 |

관능과학이 확립한 감각↔감각 관계는 열 몇 개다(`docs/grammar/01_vocabulary.md`: "IN 은
작게 두는 층"). `L×L` 을 채우겠다는 것은 존재하지 않는 지식을 채우겠다는 것이다.

**(c) 이중 계산.** 지방을 올리면 크리미함과 바디가 같이 오른다. 이것은 지방→크리미함,
지방→바디 두 컴포넌트가 이미 말한다. `L×L` 에 크리미함→바디를 또 적으면 같은 원인을
두 번 센다. 이 논리가 `IN` 을 인과 6건 / 겹침 7건으로 가른 이유다(C4).

### 2.3 고안점 1 의 답 — 제형 특성을 수식에 넣는 세 방식

| 방식 | 수식 | 지금 | 판정 |
|---|---|---|---|
| ① 선택자 | `B_profile` = 스코프가 튜플에 맞는 컴포넌트만 | **이것** (B5 매칭) | 유지. 지식이 스코프 단위로 적혀 있어 자연스럽다 |
| ② 계층 축소 | 자식 제형의 B 를 부모(SC)의 B 로 수축 — 자식 값이 없으면 부모 값을 확신도 한 단계 낮춰 씀 | B5-1 "가장 가까운 제형에서 빌림" 이 근사 | 유지. 완전한 계층은 *Deferred #1* |
| ③ 연속 함수 | `B(θ)`, θ = 제형 파라미터(점도·지방분율·pH …) — 제형을 연속량으로 | 없음 | **지금은 불가.** θ 에서 B 로 가는 함수를 추정할 데이터가 없다. 제형 7개 × 실측 1개 |

③이 궁극적으로 맞는 방향이지만(드레싱과 소스의 차이는 이름이 아니라 점도 범위다), 그것은
제형이 수십 개·실측이 수백 건일 때의 일이다. 지금은 ①+② 로 가고, **③의 씨앗은 이미
심겨 있다** — `discriminators`(제형을 가르는 파라미터 범위)가 B5-1 의 거리 함수다.

## 3. 항 2 — `Γ = stack` : 그대로, 세부 둘

- **필러 행을 뺀다.** `Σx = 100` 이라 p 개 열이 선형종속이다(해설 1.1). 필러 w 를 잔량으로
  두면 `γ_j ← γ_j − γ_w` 로 뜻이 바뀐다: "필러를 밀어내며 j 를 올릴 때". `Γ₀ ∈ ℝ^{q×m}`.
- **열은 m 개.** L = 216 열 중 이 제형 카드에 없는 축은 열을 두지 않는다. 카드가 곧 열
  선택자다(D1: 카드는 뷰). 그래서 "Γ 는 ING×L" 이라는 법전 §0 의 말은 개념이고, 계산은
  `q×m` 이다.
- Γ 에는 **짝이 있다**: 같은 크기의 사전 정밀도 `Λ`(확신도 high 8 · medium 2 · low 0.4).
  설계안에는 Λ 가 없는데, 항 5·6 의 답이 전부 Λ 에서 나온다.

## 4. 항 3-2 — `S = x·Γ` 와 `Σx = 100`

세 가지를 고쳐야 식이 선다.

**(a) 절편.** `S = x·Γ` 에 절편이 없다. 절편을 두면(`S = a + x·Γ`) `[1 | X]` 가 rank 부족이라
(a, Γ) 가 식별되지 않는다 — 실측에서 열 7 · rank 6 으로 확인. 필러 기준으로 바꾸면
`S = α + z·Γ`, α 식별됨.

**(b) 단위.** 설계안의 `v(ING)` 원소는 "1 SD 당 눈금"(weak/medium/strong = 0.3/0.6/1.0)이라
**양이 없다**. 그러므로 x 를 그대로 곱하면 안 되고 표준화한 `z^c = (z − z̄)/s`, `s = (상한−하한)/2`
를 곱한다. 이 s 가 팔레트 범위에서 오고, 그래서 범위가 "사전의 단위" 다(`bounds_strategy.md`).

**(c) S 의 정의.** 이것이 가장 중요하다. remi 의 S 는 절대 관능이 아니라 **벤치마크 대비 Δ**
다. 그러면 벤치마크 배합 `z_b` 에서 `S = 0` 이고

    S = (z − z_b)/s · Γ            절편이 사라진다 (α = 0)

설계안 항 4 의 `S_k` 가 바로 이 절편이고, 벤치마크 대비 척도에서는 정의상 0 이다(§6).

## 5. 항 3-1 — `S' = S + S·M` 과 고안점 3

### 5.1 수학적 사실 셋

**(i) 선형이면 M 은 Γ 에 흡수된다.**

    S' = S(I + M) = z·Γ(I + M) =: z·Γ'

데이터 (z, S') 로는 Γ' 만 추정된다. Γ 와 M 을 나눌 방법이 **원리적으로 없다**(식별 불능).
그러니 M 을 예측식에 넣고 실측으로 적합하면, 배운 것이 Γ 인지 M 인지 말할 수 없고,
`IN` 을 고쳐도 예측이 안 바뀐다(Γ̂ 가 이미 흡수했으므로).

**(ii) 한 단계 전파냐 완전 전파냐.** `S(I+M)` 은 축→축 영향을 **한 번만** 전파한다. 단맛→쓴맛
억제, 쓴맛→단맛 … 순환이 있으면 완전 전파는

    S' = S(I − M)^{-1} = S(I + M + M² + …)     수렴 조건: ρ(M) < 1

`IN` 6건의 크기(0.2~0.6)면 수렴하지만, 한 단계와 완전의 차이(M² 항)는 0.04~0.36 이라
±3 척도의 잡음(σ 0.5~1.8) 아래다. 어느 쪽이든 실측으로 구별되지 않는다 — 넣을 이유도
없다는 뜻이다.

**(iii) 상관은 M 에 넣지 않는다.** `IN` 13건 중 7건은 상관(크리미함~바디, 흐름성~걸쭉함 역)
이다. 원인이 하나(지방·점도)라 그 원인의 컴포넌트가 이미 둘을 움직인다. M 에 넣으면
이중 계산. 이 7건의 자리는 **Σ₀ 의 비대각**(잔차공분산 — "같이 흔들린다")과 **B1 SCOPE
의 겹침 경고**("둘 다 core 로 두지 마라")다. 이미 그렇게 되어 있다(해설 4.3, C4).

### 5.2 고안점 3 — M 을 어디에 적용하나: 후보 넷

| 자리 | 수식 | 장점 | 문제 | 판정 |
|---|---|---|---|---|
| ① 예측식 | `ŷ = z·Γ(I+M)` | 직관적 | (i) 식별 불능 · (iii) 이중 계산 · 실측이 M 의 몫을 Γ̂ 에 흡수해 `IN` 이 뜻을 잃음 | **하지 않는다** |
| ② **목표 이동 (R-3)** | 사용자가 말한 목표 `S_t^said` → 모형이 맞출 목표 `S_t = S_t^said − S_t^said·M_causal` (한 단계) | M 은 사용자 말과 축 사이의 통역이라 예측과 독립 · 실측이 M 을 건드리지 않음 · 법전 C4 가 이미 이 자리로 정함 | 인과 6건만 (상관 7건 제외) | **여기** |
| ③ Σ₀ 비대각 | `Σ₀[i,j] = ±ρ σ_i σ_j` | 마할라노비스 거리 W = Σ⁻¹ 가 상관된 축의 이중 벌점을 피함 | 크기 ρ(0.2/0.4/0.6)는 미측정 | 이미 함. 상관 7건의 자리 |
| ④ 설명 | "바닐라를 올려서 단맛이 올라 보인 것" | 사용자 신뢰 | 템플릿으로만 (특허 C-1: LLM 에 경로를 주지 않는다) | 한다 |

**②의 예.** 사용자: "덜 달게(−1), 바닐라 향은 올려(+1)". `IN`: 바닐라 향 → 단맛 강화
(+, medium 0.4). 모형이 맞춰야 할 단맛 목표는 −1 − (+1)(0.4) = **−1.4** — 바닐라가 단맛을
0.4 만큼 돌려주므로 당류는 그만큼 더 내려야 사용자가 느끼는 단맛이 −1 이 된다. 이것이
"목표 이동" 이고, Γ 는 건드리지 않는다.

**②의 수식 (한 단계, 인과만).** `M_c` = 인과 `IN` 만 넣은 m×m (부호 = enhance +, suppress −;
크기 0.2/0.4/0.6; 스코프 매칭). 열 벡터 `t_said` 에 대해

    t_model = t_said − M_cᵀ t_said          (from → to 이므로 전치)

`propose` 에는 `t_model` 을 넘긴다. 사용자 화면은 `t_said` 를 그대로 보여 주고, 차이가
0.3 이상인 축은 "왜 이동했나" 한 줄을 붙인다(④). 이것이 S3 의 구현 항목이고 `app/warmloop.
suggest` 앞단 30줄이다.

### 5.3 항 5 후반의 `S'_1 = (S_0 + Δx)M + (S_0 + Δx)`

`S_0 ∈ ℝ^{1×L}` 과 `Δx ∈ ℝ^{1×#ING}` 은 더할 수 없다. 뜻은 아마

    x_1 = x_0 + Δx,   S_1 = x_1·Γ,   S'_1 = S_1(I + M)

일 텐데, 5.2 에 따라 M 은 여기(예측)가 아니라 목표 쪽에 붙는다. 그리고 Δx 자체가 문제다
(§8).

## 6. 항 4 — `S_t = S_0·Γ + S_k` 와 `S_k` 의 정체

**차원.** `S_0 ∈ ℝ^{1×L}`, `Γ ∈ ℝ^{#ING×L}` — `S_0·Γ` 는 정의되지 않는다(내부 차원 L ≠ #ING).
쓰려던 것은 `x_0·Γ` (x_0 = 초기 **배합**)다. 설계안이 S_0 를 "sensory of initial formulation"
이라 부르면서 배합 자리에 놓은 것은 기호의 겹침이다.

**S_k 의 정체.** `S_t = x_0·Γ + S_k` 에서 S_k 는 절편 = "x = 0 일 때의 관능" 인데 배합에서
x = 0 은 존재하지 않는다(합 100). 필러 기준으로 다시 쓰면 S_k = β_w·T = **필러 100% 의
관능**, 즉 뜻은 있지만 잴 수 없는 수다. 벤치마크 대비 척도로 바꾸면

    S_t − S_bench = (x_0 − x_bench)·Γ_free/s      ⇒  S_k ≡ S_bench ≡ 0

**S_k 는 상수가 아니라 벤치마크의 존재를 뜻한다.** 벤치마크 없이 절대 관능으로 가면 S_k 를
데이터로 추정해야 하고 n = 0 에서는 불가능하다. remi 가 "벤치마크 대비 ±3" 을 척도로 고집하는
수학적 이유가 이것이다 — 절편 문제가 정의에서 사라진다.

## 7. 고안점 2 — 역산: Moore–Penrose 가 왜 안 되고 무엇으로 대체하나

### 7.1 의사역행렬이 푸는 문제

`t = Δz·Γ` 에서 `Δz = t·Γ⁺`. Γ⁺ 는

- m < q (축 < 재료, 보통): 해가 무한히 많고(영공간 q − m 차원) Γ⁺ 는 **최소노름** 해 —
  "원점에서 가장 가까운" Δz. 원점이 z̄(범위 중앙)냐 z_0(현 배합)냐에 따라 답이 다르다.
- m > q: 해가 없고 Γ⁺ 는 **최소제곱** 해.

어느 쪽이든 Γ⁺ 는 **제약을 모른다** — `0 ≤ x`, `하한 ≤ z ≤ 상한`, `Σz ≤ 100`(필러 ≥ 0).
그리고 축 사이 가중(W)도 없다 — 모든 축을 유클리드로 같은 무게.

### 7.2 실제 사례 (RV_rice_milk, 재료 11 · 축 5)

목표: 단맛 +1, 바디감 −1. 팔레트 범위 그대로.

| 방법 | 범위 위반 | 필러 | 예측 오차 max | Σ|Δz| | 비고 |
|---|---|---|---|---|---|
| 의사역행렬 | **1/11** — 잔탄검 0.24 → **−0.68 %** | 0.1 | 0.000 | 3.74 | 음수 재료. 알룰로스 25.39 는 상한 25.76 직전 |
| 의사역행렬 + 클리핑 | 0 | — | **1.478** | | 위반을 자른 순간 목표를 놓친다 — 척도의 절반 |
| 제약 QP (`propose`) | 0 | 0.3 | 1.092 | 4.66 | 범위 안에서 가장 가까운 배합. 잔탄 0, 팜유 ↓, 해바라기유 ↑ 로 분산 |

QP 도 1.092 가 남는 것은 **이 목표가 이 범위 안에서 닿지 않기** 때문이다(바디감 −1 은
잔탄을 0 으로 해도 모자란다). 의사역행렬의 0.000 은 "닿는다" 가 아니라 "음수 재료를 쓰면
닿는다" 이고, 그 정보를 사용자에게 줄 수 없다. QP 의 1.092 는 "이 범위로는 여기까지" 라는
**C5 Feasibility 의 답** 그 자체다.

또 하나 — 의사역행렬은 **두 재료만** 움직였다(알룰로스·잔탄). 최소노름은 지렛대가 큰 재료에
몰린다. QP 의 `stay‖z − z_0‖²` 는 현 배합에서의 거리라 여러 재료로 분산된다.

### 7.3 대체 — 이미 있는 것

    min_z (ŷ(z) − t)ᵀ W (ŷ(z) − t) + stay·‖z − z_0‖²
    s.t.  하한 ≤ z ≤ 상한,  Σz ≤ T − 필러하한

볼록 이차계획(해설 6.2). 의사역행렬은 이것의 극한이다 — `W = I, stay → 0, 제약 없음` 일 때
`Δz = t·Γ⁺`. 즉 **의사역행렬을 버리는 게 아니라 제약과 가중을 붙인 것**이다. Tikhonov 로
쓰면 `Δz = t·Γᵀ(ΓΓᵀ + λI)^{-1}`, λ = stay.

계산 비용: q ≤ 30 에서 SLSQP 0.01~0.05 s. 의사역행렬 SVD 도 같은 자릿수. **효율 차이 없음.**

"구할 수 있는 다른 방식" 을 더 묻는다면 — 정수·이산 제약(재료 종수 제한)이 필요해질 때
MIQP 로 가면 되고, 그 전까지는 `trim`(빼도 비용이 tol 미만이면 빼고 필러로 돌려줌)이
그 역할을 한다.

## 8. 항 5 — `ΔS` 로 `Δx` 를 역산해 배합을 고친다: 왜 발산하나

### 8.1 설계안의 반복

    S_r = 실측(x_k)
    Δx = (S_r − S_t)·Γ⁺          ← 사전 Γ 그대로
    x_{k+1} = x_k − Δx

(설계안은 `ΔS = S_0 − S_t` 로 적었는데 손글씨 원본대로 `S_r − S_t` 가 맞다. 그리고 부호는
`x − Δx` 다 — `+` 로 두면 목표에서 멀어진다.)

이것은 고정점 반복 `x_{k+1} = x_k − (x_k Γ_true − S_t) Γ⁺` 이고, 수렴 조건은
`ρ(I − Γ_true Γ⁺) < 1` — **진짜 Γ 가 사전 Γ 와 비슷할 때만** 수렴한다. 그런데 `S_r ≠ S_t`
가 된 이유가 바로 Γ 가 틀려서다. **틀렸다고 알려 준 Γ 로 다시 역산하면** 같은 방향으로
또 틀린다. 부호가 틀린 컴포넌트가 있으면 그 방향은 발산한다.

### 8.2 시뮬레이션 (RV_rice_milk 사전 Γ₀ · 진짜 Γ 는 크기 ±50% 흔들고 부호 일부 반전 · 잡음 σ 0.15 · 20회 평균)

목표 단맛 +0.8 · 바디감 −0.5. 라운드 1→6 의 `max|S_r − S_t|`:

| 진짜 Γ 의 부호 반전 | 고정 Γ₀ 반복 역산 (설계안) | 웜루프 (실측으로 Γ̂ 갱신 → QP) |
|---|---|---|
| 0 % | 0.81 0.83 0.88 0.75 0.78 0.72 · 발산 25 % | 0.83 0.79 0.72 0.59 0.49 0.58 |
| 20 % | 0.81 1.07 1.20 1.28 **1.48** 1.42 · **발산 85 %** | 0.86 0.78 1.11 0.87 0.92 0.90 |
| 40 % | 0.81 1.39 1.64 1.78 **1.98** 1.89 · **발산 90 %** | 0.86 0.80 1.36 1.09 1.00 0.99 |

(발산 = 6번째 오차 > 1번째. 코드는 이 문서 끝 부록.) 부호가 하나도 안 틀려도 고정 Γ₀ 는
잡음에 흔들리며 제자리고, 20 % 만 틀려도 라운드마다 **나빠진다**. 웜루프는 유계다 —
좋아지는 속도가 느린 것은 q = 11 인데 n = 6 이라 6 방향밖에 못 배우기 때문이고(해설 7.1),
그것이 "실험 횟수 정책" 문제의 실체다.

### 8.3 대체 — 잔차는 배합이 아니라 Γ 를 고친다

실측 하나 `(z, S_r)` 가 들어오면 축 k 마다

    γ̂_k = (Z^{cT} Z^c + Λ_k)^{-1} (Z^{cT} y^c_k + Λ_k γ_{0k})

n = 1 이면 이것은 rank-1 갱신이다:

    γ̂_k = γ_{0k} + A_k^{-1} z^{cT} (S_r,k − z^c γ_{0k}),   A_k = z^{cT} z^c + Λ_k

**잔차 `S_r − z·Γ₀` 가 `z` 방향으로만, Λ 가 허락하는 만큼만** Γ 를 민다. 확신 high(8)인
컴포넌트는 실측 8 건어치 무게로 버티고 low(0.4)는 한 번에 자리를 내준다. 그 다음 새 Γ̂ 로
QP 를 다시 푼다. 이것이 웜루프이고 설계안 항 5 의 올바른 형태다.

설계안의 `ΔS = Δx·Γ` 는 그 안에서 **예측 오차의 정의**로 살아남는다 — 잔차 = `S_r − z·Γ̂`
이 다음 갱신의 입력이다.

## 9. 고안점 4 — GP 와 확신도를 어디에

### 9.1 확신도 — 이미 세 곳에 들어가 있다

| 무엇 | 어디 | 수식 |
|---|---|---|
| 컴포넌트 확신도 (high/medium/low) | 사전 정밀도 Λ | `λ = 8 / 2 / 0.4` = "범위 끝에서 끝으로 몇 번 실험한 무게" (해설 3.3) |
| 축의 측정 확신도 | Σ₀ 대각 | `σ = 0.5 / 1.0 / 1.8` → W = Σ⁻¹ 에서 정밀한 축이 13배 무거움 |
| 예측이 얼마나 믿을 만한가 | 예측 분산 | `Var(y_k) = σ_k²(z A_k^{-1} zᵀ + 1)` — 실험 안 한 방향으로 외삽할수록 큼 |

설계안에 빠진 것은 이것뿐이다: **확신도가 Γ 의 원소가 아니라 Γ 와 같은 크기의 둘째 행렬
Λ** 라는 점. 그것이 항 5 의 발산을 막는 장치다.

### 9.2 GP — 셋 중 하나만

| 용도 | 판정 | 이유 |
|---|---|---|
| ① 반응 모형을 GP 로 (선형 대신) | **지금 아님** | n = 5~20, q = 10~30. GP 는 커널 초모수를 데이터로 정해야 하는데 n < q 에서는 사전(온톨로지)을 넣을 자리가 없다 — 선형 + ridge-to-prior 가 이 체제의 답. n ≥ 30 쯤부터 **선형 위의 잔차 GP**(semi-parametric)로 비선형을 얹는 것은 가능. `learn.py` 의 PLS/GP LOO 비교는 그 시점을 알려 주는 **검증 도구**로 남긴다 |
| ② DoE 에 GP 서로게이트 + 획득함수(EI/UCB) + 배치 다양성 | **하지 않는다** | 특허 B-28 과 문자 그대로 겹침(`특허_경계_TuringLabs_모형.md` 6.1). 공지 기술이지만 갈 이유가 없다 |
| ③ 실험 선택 | **D-최적 (권장)** | `x_{t+1} = argmax log det(Λ_t + z zᵀ/σ²)` — 사전 정밀도가 가장 커지는 배합. GP·획득함수·시뮬레이터 없음. 멈춤 규칙 `tr(Λ_t^{-1}) < 문턱` 이 "실험 횟수 정책". 6.2(a) |

용량-반응(threshold·saturating)은 GP 가 아니라 **재료 좌표의 단조 변환** `φ_κ(z)` 로
(해설 9절, 승인 대기). 모형은 φ(z) 에 대해 여전히 선형이라 3~8절이 전부 선다.

## 11. 결론 — 설계안에서 살아남는 것과 바뀌는 것

**살아남는 것.** `Γ = stack v(ING)` · `S = z·Γ` 의 선형 구조 · `ΔS = Δz·Γ` 가 오차의 정의라는
점 · "M 은 감각↔감각" 이라는 층 구분 · "확신도를 모형에 넣어야 한다" 는 문제의식. 전부
remi 에 이미 그 형태로 있다.

**바뀌는 것.**

| | 설계안 | 대체 |
|---|---|---|
| 가운데 행렬 | `L×L`, 제형별 | `P×L` 컴포넌트에 `scope` 튜플 (있음) |
| 좌표 | `x`, 합 100 | 필러 기준 `z`, 범위 표준화, 벤치마크 대비 (있음) |
| M 의 자리 | 예측식 | **목표 이동 R-3** + Σ₀ + 설명 (**S3 구현 항목**) |
| S_k | 상수 | 벤치마크 = 0 (정의) |
| 역산 | Γ⁺ | 제약 QP + W = Σ⁻¹ + stay (있음) |
| 잔차의 용도 | Δx 역산 | Γ̂ 갱신(rank-1, Λ 가중) → QP (있음) |
| 확신도 | 미정 | Λ · Σ₀ · 예측분산 (있음) |
| GP | 미정 | 지금 안 씀. DoE 는 D-최적 (**S3 설계 항목**) |

**S3 의 다음 일 (이 문서에서 나온 것).**
1. R-3 목표 이동 — `IN.interactions` 6건으로 `M_c`, `t_model = t_said − M_cᵀ t_said`,
   `warmloop.suggest` 앞단. 화면에 이동량과 한 줄 이유.
2. C5 Feasibility — QP 의 잔여 오차 `‖ŷ − t‖_W` 가 곧 "이 범위로는 여기까지". 축별로 내고
   범위를 어느 쪽으로 넓히면 닿는지(라그랑주 승수 = 제약의 그림자 가격)를 같이 낸다.
3. D4 — D-최적 후보 선택과 멈춤 규칙. `doe.py` 의 v1 요인 설계를 대체.
4. 용량-반응 φ_κ (승인 대기).

## 부록 — 실험 코드 (재현)

`python -` 로 저장소 루트에서. 팔레트의 RV_rice_milk 행(범위 있음 11)을 쓴다.

```python
import sys, numpy as np
sys.path[:0] = ["engine", "app"]
from formulator.v2adapter import V2Ontology
from formulator.mixture import propose, MixtureModel
import palette as pal
onto = V2Ontology(); prof = "RV_rice_milk"
tab = pal.load(prof); ids = tab.palette(only_with_range=True); bounds = tab.bounds()
b = onto.build(prof, ids, bounds=bounds); m = b.model
free = [n for n in b.palette if n != b.filler]; idx = [b.palette.index(g) for g in free]
lo = np.array([bounds[g][0] for g in free]); hi = np.array([bounds[g][1] for g in free])
x0 = np.zeros(len(b.palette))
for g in free: x0[b.palette.index(g)] = b.zbar[free.index(g)]
x0[b.palette.index(b.filler)] = 100 - x0.sum(); z0 = x0[idx]
Graw0 = m.G / b.zsd[:, None]
mm = len(b.y_terms); t = np.zeros(mm); t[0] = 0.8; t[1] = -0.5

# §7.2 — 의사역행렬 vs QP
t1 = np.zeros(mm); t1[0] = 1.0; t1[1] = -1.0
zp = z0 + t1 @ np.linalg.pinv(Graw0)                       # 잔탄검 -0.68
zq = np.asarray(propose(m, target=t1, x0=x0, lo=lo, hi=hi))[idx]

# §8.2 — 고정 Γ₀ 반복 vs 웜루프
def full(z):
    x = np.zeros(len(b.palette)); x[idx] = z; x[b.palette.index(b.filler)] = 100 - z.sum(); return x
def experiment(seed, flip_p, noise, K=6):
    rng = np.random.default_rng(seed)
    Gt = m.G * rng.uniform(0.5, 1.5, m.G.shape); Gt[rng.random(Gt.shape) < flip_p] *= -1
    S_true = lambda z: (z - z0) @ (Gt / b.zsd[:, None]) + rng.normal(0, noise, mm)
    z = z0.copy(); ea = []
    for k in range(K):
        Sr = S_true(z); ea.append(np.abs(Sr - t).max())
        z = np.clip(z - (Sr - t) @ np.linalg.pinv(Graw0), lo, hi)
    z = z0.copy(); X, Y, eb = [], [], []
    for k in range(K):
        Sr = S_true(z); eb.append(np.abs(Sr - t).max()); X.append(full(z)); Y.append(Sr)
        mdl = MixtureModel(b.palette, b.filler, 100.0)
        mdl.fit(np.array(X), np.array(Y), prior=m.G, prior_precision=m.Lam, zsd=b.zsd)
        z = np.asarray(propose(mdl, target=t, x0=X[-1], lo=lo, hi=hi))[idx]
    return ea, eb
```
