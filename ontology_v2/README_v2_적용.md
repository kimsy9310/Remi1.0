### 1.3 mixture.py 세 곳을 고쳤다

수정 전 파일은 `engine/formulator/mixture.py.bak_20260824_165135` 에 있다.

**B1 — 사전계수 스케일.** `fit_prior_only` 가 `zsd` 를 조용히 `1` 로 두고 있었다.
사전은 "1 표준편차당 효과" 인데 모형은 "1 퍼센트포인트당" 으로 읽었다.

```
고치기 전:  알룰로스 20 pp  ->  단맛 +20.0     (관능 척도는 ±3 에서 포화)
```

이것 때문에 옵티마이저가 "이미 너무 달다" 고 판단해 감미료를 전부 빼버렸다.
이제 `zsd` 는 필수 인자다. 사전이 이미 원단위라면 `zsd="unit"` 으로 **명시적으로**
선택해야 한다. 기본값을 없앤 이유는, 멈추지 않고 틀리는 오류였기 때문이다.

**B3 — Γ₀ 행 수.** 조립기는 팔레트 전체에 대해 Γ₀ 를 만들지만 모형은 필러를 뺀
자유변수를 쓴다. 검증이 없어서 한참 뒤 `propose()` 안에서 broadcast 오류로
터졌다. 이제 적합 시점에 거부하고, 메시지가 필러 행을 빼라고 알려준다.

**B4 — 엣지별 확신도.** Λ 를 `(q,)` 로만 받아서 호출부가 재료별 최솟값으로
축약해야 했다. 실측해보니 `{0.4, 2.0, 8.0}` 세 값이 **한 값으로** 뭉개졌다 —
구조화 베이지안의 핵심이 사라진다. 이제 `(q, m)` 을 받고 반응 열마다 능선
방정식을 따로 푼다(열끼리 독립이라 근사가 아니다). `(q,)` 도 계속 받는다.

`fit()`, `predict()`, 유효 자유도 계산이 함께 바뀌었다. `Ainv` 는 이제
`(m, q, q)` 다.

### 1.4 어댑터가 생겼다

`engine/formulator/v2adapter.py`. v1 로더는 **고치지 않고 그대로 뒀다** — v1
온톨로지로는 여전히 정상 동작한다(확인함: structure_classes 3 · params 29 ·
sensory 55). v1 로더에 v2 를 넣으면 예외 없이 빈 객체가 나오므로, 섞어 쓰지 말 것.

built = onto.build("icecream", palette, bounds=상한표)
print(built.report())                      # 왜 이런 모형이 됐는지

### 5.2 효과를 내지 못하던 재료 24종

### 5.3 propose 를 QP 로

`propose()` 가 경사하강이었고 학습률이 스칼라 하나라, 가장 가파른 방향이 그
값을 정해버렸다. 식품 배합은 스케일 폭이 크다(트러플 향료 0.01% vs 해바라기유
70% → zsd 비율 450배). 나머지 방향은 사실상 얼어붙었다.

기본 `iters=3000` 과 완전수렴의 오차:

| 제품 | zsd 비율 | 오차 (±3 척도) |
|---|---|---|
| 트러플 마요 | 450 | 0.956 |
| 오레가노 케첩 | 48 | 0.587 |
| 체리 코크 | 50 | 1.077 |

관능 한 단위가 통째로 틀어졌다. 좌표별 스텝(대각 전처리)을 먼저 시도했으나
비대각 결합이 강해 오히려 발산했다(오차 5.8).

근본 원인은 도구 선택이었다 — 이건 **박스 제약이 붙은 볼록 이차계획**이지
일반 비선형 문제가 아니다. scipy SLSQP 로 바꾼 결과:

    트러플 마요   0.950 · 0.30s  ->  0.019 · 0.05s
    체리 코크     1.077 · 0.30s  ->  0.000 · 0.01s

`solver="auto"` 가 기본이며 scipy 가 없으면 기존 경사하강으로 물러난다.
`solver="gd"` 로 예전 동작을 강제할 수 있다(회귀 비교용).

| M 카드·S 프로파일이 가리키는 ID | 깨진 것 **0** |

**렉시콘은 사실상 완결돼 있다.** 세 제품 테스트에서도 새 용어가 필요 없었고,
이번 구조 점검에서도 흠이 없었다. 병목은 계속 C 층이다.

### 6.2 R-1 고아 15건 → 3건

`layerC2_ext_scope_completion.yaml` (신규, DRAFT).

원인은 앞서 두 번 고친 것과 같은 패턴이었다 — v1 이 C 엣지를 **한 스코프에만**
썼는데 R-1 은 여러 스코프에 걸쳐 있다. 관계의 절반만 있고 나머지 절반이 비어
있었다.

정의에 가깝거나 HANDOFF 에 문서화된 것만 채웠다. 대표적으로:

- `FT.sweetener -> P.soluble_solids_brix` (any) — R-1 의 sweet 관계가 scope=any
  인데 이 파라미터를 움직이는 엣지는 음료의 개별 재료 둘뿐이었다
- `FT.thickener -> P.yield_stress` (sauce/suspension) — 이것이 없어
  `L.tx.spreadability` 가 어떤 재료로도 움직이지 않았다
- `FT.stabilizer -> P.ice_crystal_size` (icecream) — HANDOFF 의 "구아검 = 얼음결정
  억제 주력"
- `FT.sweetener -> P.ice_phase_volume` (icecream) — "설탕의 3중 역할" 중 빙점강하
  고리

**남긴 3건**은 지어내지 않았다. 이유는 파일 하단에 적었다 —
`P.serving_temperature`(제공 조건), `P.particle_size_d90`(스펙 §5.9 가 명시한
변종 선택 영역), `P.flavor_release_dynamics`(**파라미터 정의 자체가 모호**하다.
라벨이 "Flavor release / matrix binding" 으로 반대 개념 둘을 담고 있어 방향을
추측하면 부호가 뒤집힐 위험이 있다).

### 6.3 여운 축이 온톨로지 전체에 없었다

`L.ta.aftertaste_length` 는 **직접 엣지가 0건**이었고, 소스에서만 R-1(지방)으로
간신히 닿아 나머지 4개 프로파일에서는 아예 움직이지 않는 축이었다.

고감미도 감미료의 여운은 이 제품군의 대표적 약점이자 저당 트랙의 핵심
트레이드오프인데 기록이 없었다. 에리스리톨의 쿨링도 마찬가지였다(HANDOFF 가
경고하고 있는데도). 둘 다 재료 단위로 보탰다 — 벌크 감미료와 갈리는 지점이라
`FT.sweetener` 에 걸면 안 된다.

### 6.4 별칭 파일의 기계가독성

`_deprecated_aliases.yaml` 은 스스로 "machine-readable" 을 표방하는데
`deprecated_sa_special` 절만 값이 산문이었다. 도구가 `SA.oiliness` 를 물으면
ID 가 아니라 문장을 받는다. 산문은 `note` 로 남기고 `kind`/`targets` 를
나란히 두어 60건 전부 기계로 해석된다.

### 6.5 감사 정교화

`audit()` 이 숙성 속성(`sample_aged`)을 오탐하고 있었다. 배합이 아니라 시간이
만드는 것이라 R-4 kinetics 가 담당하는 것이 맞다(스펙 §5.8). R-4 가 덮고 있으면
결손이 아니다 — `L.ap.darkened` 가 그 경우다(KN.0003).

지금 남은 미도달 활성 용어는 `L.tx.cold_perceived` 하나뿐이고, 제공 온도라
탄산과 같은 Layer O 영역이다.

### 6.6 부수 효과 — 실측과의 불일치가 사라졌다

웜루프를 다시 돌리니 **사전과 부호가 뒤집힌 칸이 2건에서 0건**이 됐다.

    ING.sunflower_oil -> L.tx.body    실측 -0.11  ->  +0.23  (사전 +0.30 과 일치)

사전이 전반적으로 잘 지정되자 모형이 바디 변화를 엉뚱한 재료에 돌리지 않게
된 것이다. 사전이 채워진 칸도 늘었다(13칸).

### 6.7 남은 판단 — 렉시콘

**신선한 홍고추 향 용어가 없다.** `ING.chili_fresh_red` 를
`L.ar.fresh_chili_green` 에 약하게(weak/low) 걸어 두었다.

추가할지는 렉시콘 소유자의 판단이라 손대지 않았다. 근거는 이렇다.

- `green_vegetal` 경계 규칙: "Fresh/cooked vegetable and green aromatics" (목표 9종)
- `spice` 경계 규칙: 예시가 "dried red chili"
- 신선한 홍고추는 두 경계 **사이**에 걸친다 — 신선하지만 초록이 아니고,
  붉지만 건조되지 않았다
- 렉시콘 규칙은 "유사어는 병합하고 근사 중복을 추가하지 말라"

훈련받지 않은 평가자의 벤치마크 상대평가 수준에서는 현재 매핑으로 충분할
수 있다. 정밀하게 가르고 싶으면 `L.ar.fresh_chili_red` 를 `green_vegetal` 에
추가하고 boundary rule 을 "green" 에서 "fresh capsicum" 으로 넓히는 편이 맞다.
